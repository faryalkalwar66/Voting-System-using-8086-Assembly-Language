Project Title:
COAL Voting System using 8086 Assembly Language

Introduction:
The COAL Voting System is a console-based electronic voting application developed in 8086 Assembly Language. The purpose of this project is to demonstrate the practical implementation of low-level programming concepts using Assembly Language. The system simulates a basic election environment where users can register as voters, securely log in, cast votes, and view election results. The project is designed for educational purposes and highlights how Assembly Language can be used to build real-world management systems.

Objectives:
• To understand the concepts of Assembly Language programming.
• To implement loops, arrays, procedures, and conditional statements in 8086 Assembly.
• To create a secure voting mechanism with login authentication.
• To develop a menu-driven console application.
• To perform vote counting and winner calculation using Assembly instructions.

System Features:
• Voter Registration System
• Automatic Voter ID Generation
• PIN-based Secure Login
• One Person One Vote Validation
• Live Vote Counting
• Winner Announcement
• Admin Panel Access
• Error Handling and Input Validation

Tools and Technologies Used:
• 8086 Assembly Language
• Microsoft Macro Assembler (MASM)
• DOSBox Emulator
• DOS Interrupts (INT 21H)
• Microsoft Word for Documentation

Working Methodology:
1. The system first displays a welcome screen and list of election candidates.
2. A new user can register by entering a 4-digit PIN.
3. The system automatically assigns a unique voter ID.
4. Registered users can log in using their voter ID and PIN.
5. After successful authentication, the voter can cast a vote.
6. The system ensures that a voter can vote only once.
7. Vote counts are stored and displayed in real time.
8. The admin panel allows monitoring of total votes and voter activity.
9. At the end, the system announces the winner based on maximum votes.

Advantages of the System:
• Secure voting process
• Prevents duplicate voting
• Simple and user-friendly interface
• Efficient vote counting
• Demonstrates low-level memory handling

Conclusion:
This project successfully demonstrates the implementation of a voting management system using 8086 Assembly Language. It provides practical understanding of Assembly programming concepts such as memory management, arithmetic operations, loops, procedures, arrays, and interrupt handling. The project also enhances problem-solving skills and demonstrates how low-level languages can be used to create complete functional applications.
